# Konica Prasher: Academic Website

A static, responsive academic homepage (HTML + CSS, no build step, light/dark mode aware).

## Files
- `index.html`: all page content
- `style.css`: styling
- `cv.pdf`: add your CV with this exact name (optional, otherwise remove the "Download CV" button)

## 1. Fill in your details
Open `index.html` and replace every `[bracketed placeholder]` and `your.email@example.com`. Delete any section you don't need (for example Publications) along with its link in the `<nav>`.

## 2. Publish on GitHub Pages (github.io)
1. Create a GitHub account if needed, then click **New repository**.
2. Name it exactly `YOUR-USERNAME.github.io` (replace with your GitHub username), set it to **Public**.
3. Click **Add file > Upload files**, upload `index.html`, `style.css`, `README.md` (and `cv.pdf`), then **Commit changes**.
4. Go to **Settings > Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and Save.
5. After a minute or two your site is live at `https://YOUR-USERNAME.github.io`.

## 3. Updating later
Edit a file on GitHub (pencil icon) and commit. Changes go live in about a minute.
